# One Trait 2.8: the Character rows' hand-written triggers. For an action key K (tools/build_one_trait_panel.py,
# CHARACTER_ACTIONS): one_trait_character_K_shown_trigger and one_trait_character_K_valid_trigger. Spec:
# docs/superpowers/specs/2026-10-17-one-trait-2.8-character-pages-design.md section 2.
#
# Scope rule (plan "Names used across tasks" + R5): every trigger here runs IN the panel character's scope --
# the generated scripted GUI calls it as "var:one_trait_ui_target = { one_trait_character_K_... = yes }" --
# so the retired menu option's own "scope:one_trait_target" becomes "this" (left bare), and "root" is still
# the player. Shown = a row that can never apply is really hidden (the action row's outer visible); valid =
# greyed with CK3's own reason on hover, when the row could apply but not now.
#
# Each row carries the retired option's conditions, split per the spec: shown holds what can never apply
# (yourself, a missing relative), valid holds what could apply but not now (greyed with CK3's own reason).
# A missing relative is genuinely false in shown by explicit existence, never a bare ?= chain (R6).

# Trait keys: game/common/traits/00_traits.txt -- education_<intrigue|diplomacy|stewardship|martial|learning>_1..5
# (lines 11-868) and the add-ons education_martial_prowess_1..4 (15677-15764) / education_republican_knowledge_1..4
# (16089-16161); all have minimum_age = 16 (00_traits.txt:12 and so on). has_trait / has_sexuality: the 1.20.1.1
# triggers dump (docs/reference/ck3-1.20.1.1-triggers.log). The trait keys are written out literally below (no
# education_$X$_ pastes): tools/validate_mod.py reads has_trait / add_trait keys textually and would flag a paste.

# Education traits carry minimum_age = 16 and add_trait silently fails below it, so every picker button is
# greyed under 16. Character scope (the panel's target).
one_trait_can_edit_upbringing_trigger = {
	custom_tooltip = {
		text = one_trait_upbringing_too_young_tt
		age >= 16
	}
}

# Character scope. Any main education trait of tier n (1-5). The add-ons (prowess, republican) are never main.
