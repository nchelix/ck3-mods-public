# Changelog — Warrior Trait

## [1.3] — 2026-09-30

Compatibility update for **CK3 1.20 "Crozier"** (and the By God Alone DLC). No
gameplay values were changed: both traits are exactly as powerful as before.

### Fixed
- **Warrior experience from battles is granted reliably again.** The mod gave
  the base game's `on_combat_end_winner` hook a second `effect` block, but the
  base game already defines one there and CK3 allows only one per hook, so the
  two collided. The mod now attaches its own hook,
  `warrior_on_combat_end_winner`, through `on_actions`, which is the method the
  game documents for this. Five experience per victory, as before.

### Compatibility
- `supported_version` raised from `1.19.*` to `1.20.*`.
- Checked every trait modifier, interaction and localization key against 1.20:
  all still valid.

## [1.2] — 2026-09-22

Adds a second trait and reworks the first. This is the first release that
changes what the mod does rather than just keeping it running.

### Added
- **Warrior is now a trait you earn.** It starts as a genuinely strong fighter
  and grows towards unbeatable as its bearer personally commands victorious
  battles, using the level track system CK3 added in 1.9. Five experience per
  victory, four tiers, twenty wins to reach the top. At full strength it is
  close to the old trait; at the start it is merely very good.
- **God Warrior** is the original trait, unchanged in spirit. Everything, all at
  once, the moment it is applied. If that is what you came here for, it is still
  here, and it is now the deliberate choice rather than the only option.
- God Warrior also covers systems the 2020 version predates:
  `knight_effectiveness_mult`, `knight_limit`, `men_at_arms_cap`,
  `travel_danger` (so landless adventurers travel unharmed),
  `legitimacy_gain_mult` and `accolade_glory_gain_mult`.
- A gold icon for God Warrior so the two traits are distinguishable at a glance.
- Four interactions instead of two, one pair per trait. The two traits are
  mutually exclusive.

### Upgrading from 1.1
The trait key `warrior` now belongs to the growing version, so **a character who
already had the old Warrior trait will find it has become the earned one,
starting at zero progress**. Their old power is not gone, it just has a new
name: apply **Become A God Warrior** and they are exactly as they were. This is
the one disruptive consequence of the rename and there is no way to avoid it
while giving the plain name to the trait that deserves it.

## [1.1] — 2026-09-22

Compatibility update for **CK3 1.19 "Scribe"**. No gameplay values were changed:
the trait is exactly as powerful as it was before.

### Compatibility
- `supported_version` raised from `1.2.*` to `1.19.*`.
- Removed `index = 705`. Manual trait indexes were dropped in CK3 1.4 and are
  now assigned by the engine.
- Verified all 22 trait modifiers against 1.19 — every one is still valid and
  still used by the base game.
- Verified every key in the character interactions against the 1.19 schema, and
  that `interaction_category_friendly` still exists.

### Fixed
- `hard_casualty_modifier` and `enemy_terrain_advantage` were each declared
  twice in the trait block. Collapsed to one each (values were identical, so
  behaviour is unchanged).
- Removed `good = yes`, which only applies to genetic traits and did nothing here.
- Removed the redundant `warrior:0` localization key. The trait name comes from
  `trait_warrior`, which is the engine default for a trait called `warrior`.

### Added
- Interaction icons. Both interactions now use the base-game `icon_combat`
  sprite instead of falling back to a missing file.
- `interface_priority` on both interactions so they sort predictably in the
  friendly-interaction menu.
- Localization for all 9 languages CK3 1.19 ships (was English only). The eight
  new languages carry English text as a clearly marked placeholder, which stops
  non-English players seeing raw keys like `become_warrior_interaction`.

### Changed
- Trait icon resampled from 512x512 to 120x120 to match base-game trait icons,
  and rewritten as uncompressed BGRA8 with no mipmaps so its header is
  byte-identical to vanilla's. File size drops from 342 KB to 56 KB.
- Trait and interaction files reorganised into commented groups. No logic changed.

### Known issues
- `siege_weapon_max_size_mult` may display as a raw key rather than a friendly
  name in the trait tooltip. Modifier display names are generated by the engine
  and cannot be overridden from a mod, so this is not fixable here.
- `Thumbnail.png` is a tooltip screenshot from the 1.2 era and is portrait rather
  than square. Worth recapturing before the next Workshop publish.
